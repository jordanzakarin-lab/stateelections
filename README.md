# State Elections

Live election-night results for all 88 state legislative chambers on the ballot Nov. 3, 2026.

Copied from `flipseats.org/results/` (repo `jordanzakarin-lab/win-local`, commit c261b63).

## Files

- `index.html` — the results page (single file; loads the two JSON files below by relative path)
- `baseline.json` — pre-election chamber and district baseline
- `data.json` — live results, updated by the election-night pipeline
